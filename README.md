# Petal Planner

A page-turning yearly planner for iPad and Apple Pencil. It runs in Safari and can be added to the home screen, where it opens full-screen and works offline.

**Open it:** https://sophiakazi.github.io/Planned/

## Add it to an iPad

1. Open the link above in Safari.
2. Tap **Share**, then **Add to Home Screen**.
3. Open Petal Planner from its home-screen icon.

## Your data

Everything you write stays on your device. Nothing is sent anywhere. Use **Cover & settings → Back up planner** now and then, and keep the backup file in Files or iCloud Drive.

## What's inside

- `index.html`: the planner
- `sw.js`: offline support
- `manifest.webmanifest` and `icons/`: home-screen app details
- `vendor/page-flip.browser.js`: [StPageFlip](https://github.com/Nodlik/StPageFlip) page-turn library (MIT licence)
- `fonts/`: Cormorant Garamond, Jost and Pinyon Script from Google Fonts (SIL Open Font Licence)
